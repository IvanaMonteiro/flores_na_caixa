# 🌸 Flores na Caixa

## E-commerce de flores e presentes

O **Flores na Caixa** é uma aplicação web de comércio eletrónico desenvolvida com React, JavaScript e Vite.

O projeto apresenta uma loja virtual de flores e presentes, com uma interface intuitiva, navegação entre páginas e funcionalidades de pesquisa e carrinho de compras.

Foi desenvolvido como projeto prático de desenvolvimento web, com o objetivo de aplicar conhecimentos de frontend, organização de componentes e gestão de estado.

## 🌐 Demonstração online

**[Aceder ao Flores na Caixa](https://ivanamonteiro.github.io/flores_na_caixa/)**

## ✨ Funcionalidades

- Página inicial com apresentação da loja e dos produtos.
- Catálogo de flores e presentes.
- Pesquisa de produtos.
- Página de detalhes dos produtos.
- Seleção de produtos e gestão do carrinho.
- Navegação entre páginas.
- Interface com componentes React reutilizáveis.
- Tratamento de páginas não encontradas.

## 🚀 Executar o frontend localmente

**Pré-requisitos:** Node.js e npm instalados.

1. Clonar o repositório:

```bash
git clone https://github.com/IvanaMonteiro/flores_na_caixa.git
```

2. Aceder à pasta do frontend:

```bash
cd flores_na_caixa/frontend
```

3. Instalar as dependências:

```bash
npm install
```

4. Iniciar o servidor de desenvolvimento:

```bash
npm run dev
```

5. Abrir no navegador o endereço indicado pelo Vite no terminal.
